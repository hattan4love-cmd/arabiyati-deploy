# عربيتي • Arabiyati — تعلّم العربية بمتعة

موقع تفاعلي متجاوب لتعليم اللغة العربية لغير الناطقين بها.

**الهوية:** اِسمَعها صَحّ • اُنطُقها فَصِيحَة  
**الرسالة:** العربية للجميع — من أول حرف إلى أول حوار، بصوتٍ فصيح ونطقٍ سليم.

## المزايا
- 🔤 28 حرفاً بنطق فصيح مشكول + مثال
- 📚 مفردات يومية ببطاقات مقلوبة (تحيات، أرقام، ألوان، طعام، عائلة)
- 🎯 اختبار 8 أسئلة مع تصحيح فوري
- ✍️ لوحة كتابة + 🎧 استمع واكتب
- 🃏 لعبة ذاكرة عربي ↔ معنى
- 🎙️ صوت عربي فصيح: صوت الجهاز + جودة عالية (Google TTS)
- 🌍 واجهة بـ 7 لغات: ar, en, fr, es, tr, ur, id
- 📱 متجاوب مع الجوال + شاشة افتتاح بالشعار والترحيب

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة. لا يحتاج سيرفر.

## النشر على GitHub Pages
الموقع ملف واحد `index.html` في الجذر — جاهز لـ Pages من فرع `main` مباشرة.

## التقنية
HTML + CSS + JS فقط. الصوت عبر Web Speech API مع قاموس تشكيل فصيح + Google Translate TTS كخيار عالي الجودة.
